# Rick and Morty iOS

A native iOS application built with **UIKit** that allows users to explore characters, episodes, and locations from the Rick and Morty universe using the public Rick and Morty API.

This project was created to practice building scalable iOS applications using modern architecture and networking approaches. Although inspired by the iOS Academy tutorial, the project serves as a practical demonstration of UIKit development, networking, image loading, and clean project organization.

---

## Features

* Browse all characters
* Character details
* Browse episodes
* Episode details
* Browse locations
* Search functionality
* Pagination
* Image caching
* Responsive UI
* Smooth navigation

---

## Technologies

* Swift
* UIKit
* MVVM
* URLSession
* Codable
* Auto Layout
* UICollectionView
* UITableView
* Async Image Loading
* REST API

---

## Architecture

The project follows the **MVVM (Model–View–ViewModel)** architectural pattern.

The application is divided into separate layers:

* Models
* Views
* ViewModels
* Networking
* Resources
* Extensions
* Utilities

This separation improves maintainability, readability, and scalability.

---

## API

This application uses the public Rick and Morty API.

https://rickandmortyapi.com/
